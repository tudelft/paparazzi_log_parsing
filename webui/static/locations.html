Takeoff and landing locations

Help

Blue dots are positions where flights took off or landed, grouped to about 100 m. Use Only unnamed dots to review positions outside named places. Select a dot or use Previous / Next to visit it. Draw a boundary around it and give the place a name; covered positions leave the unnamed list after saving.

Import places from CSV

Each row is a circle (place, lat, lon, radius_m, optional indoor yes/no). A place with the same name is updated; importing the same file again changes nothing. One bad row imports nothing. Other columns of logbooks/places.csv are ignored.
