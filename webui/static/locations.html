Help

Blue dots are positions where flights took off or landed, grouped to about 100 m. Click a location in the list or on the map to select it; click a numbered group to zoom in. Boundaries appear when zoomed in. Only unnamed dots lists positions outside named places: select one or use Previous / Next to visit it, then Add location and draw a boundary around it; covered positions leave the list after saving.
New location: draw a on the map, then name it.

Import places from CSV

Each row is a circle (place, lat, lon, radius_m, optional indoor yes/no and country, e.g. NL). A place with the same name is updated; importing the same file again changes nothing. One bad row imports nothing. Other columns of logbooks/places.csv are ignored.
