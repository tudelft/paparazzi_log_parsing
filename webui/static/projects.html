Projects

Help

A project is a separate set of flight logs. Open a project to see its flights.

Import projects from CSV

Columns: project,person,role, one row per member. Roles: view, add (view/upload; default), full (also delete). Match people by unique display name or alias.

Reimport replaces all members of each included project. Omitted projects are unchanged. A blank person leaves the project without members. Any invalid row rejects the entire import.
