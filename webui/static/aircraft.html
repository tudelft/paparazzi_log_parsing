Aircraft and their aliases

Each aircraft has a unique ID that stays with it if you rename it. It is also matched automatically by its name. Aliases cover extra names from the logs (about 300 drones is fine; use the filter). Removing an aircraft keeps the logs. Unassigned flights that match get this default project first, before the uploader, GCS operator or PIC.
