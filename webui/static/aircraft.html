Unlinked aircraft names
Help

Paparazzi logs usually already have the fleet name. PX4 and Blackbox logs do not: they show the airframe type plus the flight-controller id (for example quad_x 00500040) or a filename such as LOG00030. Link that once to the real aircraft; later logs from the same board attach automatically. The dropped folder name is a hint, including a parent folder above dated subfolders, and is never used when more than one aircraft could match.

Ambiguous / shared aircraft names

Shared airframe names do not identify a physical aircraft. SD recordings may inherit a uniquely matched GCS identity in the logbook. Choosing an aircraft for a board links every recording on that board; a recording without a board ID is assigned on its own. Both survive reparsing.

Import aircraft from CSV

Reimport matches serials and updates aircraft details. Import projects first. A changed Project requires project_effective_date (YYYY-MM-DD); blank Project leaves its assignment unchanged.

The effective date starts a new project period until the next existing period. Known automatic flight assignments in that period are updated; manual and legacy assignments are preserved. Any invalid row rejects the whole file.
