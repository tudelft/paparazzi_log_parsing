Flight log database

Drop log files, zip archives or folders here
.data and .log files must come as a pair with the same name (zips and folders may contain several pairs). Files are accepted quickly; fingerprinting, duplicates and parsing run in the background. The list below shows the newest 100 logs. For hundreds of logs, drop a zip or a folder — picking thousands of files one by one can freeze the browser.
Project is set automatically from the aircraft (then the uploader, GCS operator or PIC). Admins can change it on a log after it is parsed.

You can look at logs here. Adding logs needs access from an admin.
