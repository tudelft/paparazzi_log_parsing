Qualification types

Help

Admins define qualification types here. Checked Evidence, Valid from and Valid until switches make those fields mandatory; unchecked fields are optional. Internal marks an in-house qualification rather than an external licence. Drag the handle to change the order. One Save writes every type. Both dates start checked for new types. Import a ZIP with manifest.csv and evidence PDFs to create and approve qualifications in bulk.

CSV template

Import qualifications

Upload a ZIP that contains manifest.csv and the evidence files. Preview checks people, types, dates and files. Per person and type, the latest period becomes current; older periods go to Archive. Periods already recorded are skipped, so the same ZIP can be imported again. Names not yet on People are added as new users without password or email; unknown types are added as qualification types. A row with only a name adds that person without a qualification.
