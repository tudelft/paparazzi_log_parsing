Help

Files are stored once and can be linked to multiple flights, paper records or whole logs. A file linked to a log also appears on its flights. Text and other compressible files use lossless compression; photos, videos and archives stay in their original form when compression would not help. Downloads always restore the exact original bytes. A file with the name of an existing one replaces it on that flight/log; the old file stays under "Show earlier versions".

Sharing: everyone with access to any linked flight/log can download the file. Linking across projects deliberately shares its contents with those projects.
