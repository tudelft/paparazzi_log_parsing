Help

Pick an item in the tabs, or All for every item you may see. Click a booking to open it, or an empty slot to book that time. Bookings of the same item overlap only when both set a shared option (for example "Others allowed") and neither sets a blocking one (for example "Demo"); an item without options never overlaps. Some items need a current qualification to book, or to see their agenda at all. You can change or delete your own bookings; administrators can change any and set up the items in Edit mode. Times are local.
