Help with paper records

Transcribe an individual flight or a daily total. These are paper records, not telemetry: unknown times, positions, distance and software remain unavailable. Daily totals count all flights but do not invent individual takeoffs. Check for overlapping digital logs before importing; exact paper duplicates are rejected, but overlaps with telemetry are not automatically merged.

Import paper records from CSV

Use UTF-8, comma-separated CSV. Required columns: aircraft, pic, project, date (YYYY-MM-DD), duration_minutes (total), flight_count. Use existing aircraft/project/location names and crew unique display names or explicit crew aliases, matching the log crew rules. Usernames match only when added as aliases; unknown or ambiguous crew names reject the import. Optional kind: flight or daily; takeoff_time: HH:MM[:SS] UTC. Blank time means unknown. No users or aircraft are created automatically.

Download CSV template

At most 1000 rows / 1 MB. Every row is validated before saving: if any row is invalid, nothing is imported. Dates and flight totals are kept exactly as supplied.

Importing a corrected CSV again updates the records instead of adding them twice. A row updates the record with the same reference (use a unique flight number such as F00001), or the individual flight with the same aircraft, date and takeoff time. Daily summaries and flights without takeoff time are only recognised by reference. Identical rows are left unchanged. You see what each row will do before anything is saved.

The original CSV is attached once to all records it created or updated. Anyone who can read any of those records can download the entire CSV, including rows for other projects. Failed imports keep no attachment.
