Help

A key lets a script use the API as you; it never does more than you may, and it cannot manage keys. Its scopes say what else it is limited to: read (everything a GET shows, e.g. for a script that builds a document), logs:upload (upload logs, attachments and paper records), logs:edit (project, date, crew and comment of logs and flights, reparse), and for administrators documents:upload (add a document, replace its file), documents:manage (edit and delete documents and groups) and admin (the other administration). Give a key only what its script needs. Narrow takes scopes away from a key; a key from before scopes shows as full (old) and can be narrowed too. Send it as Authorization: Bearer <key>. Revoke a key if it leaks. The Python package mavlab-logbook-client and the MATLAB tools can also sign in through the browser instead; they get a key that expires after a week.
